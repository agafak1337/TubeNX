# Задание: иконка приложения, страница 06 Icon, SVG-иллюстрации

ТЗ §6 и экспорт из §9. Папка временных рендеров: `/tmp/opencode/agent-icon/`.

Текущая иконка (`resources/icon.svg`, `resources/images/icon.png`) ТЗ не соответствует (белый «экран»,
точка-акцент, свечение, тень). Новую рисуй с нуля. Файлы в `resources/` НЕ трогай — результат только в
`design/`.

## A) Иконка

Требования §6: квадрат без прозрачности по краям (Switch показывает иконку в квадрате); форма squircle /
M3-«печенье», радиус ~22 %; фон — диагональный градиент #C3002F → #7A0020, без шума и мелких деталей; в
центре белый play-треугольник со скруглёнными углами (радиус 3–4 px в масштабе 256), оптически по центру
(сдвиг вправо на 2–3 %); без текста, теней, обводок; читается в 256, 128, 64, 48.

Противоречие ТЗ («квадрат без прозрачности» и «форма squircle») разреши явно, двумя вариантами рядом
(ТЗ §11), с отмеченной рекомендацией:

- (A) холст полностью непрозрачный, углы залиты тёмным тоном того же красного (подбери так, чтобы squircle
  читался, но углы не спорили), на нём squircle с градиентом;
- (B) градиент на весь квадрат без внутренней формы (если система сама скругляет/обрезает).

Третий вариант — только как идея: треугольник, образующий «N» с контрформой, если читается в 64×64. Если не
читается — честно напиши и не включай в рекомендацию.

Squircle — настоящая суперэллипсная кривая (path из кубических Безье, n≈4–5), не rect с rx. Треугольник —
path со скруглением дугами в самом контуре (обводки запрещены).

Файлы:

- `design/export/icon/icon.svg` — исходник 1024×1024 (viewBox 0 0 1024 1024), рекомендованный вариант;
- `design/export/icon/icon-1024.png`, `icon-256.png` (NACP), `icon-128.png`, `icon-64.png`, `icon-48.png`;
- `design/export/icon/icon-mono.svg`, `icon-mono-256.png` — монохром: белый знак на прозрачном;
- варианты B и «N» — `design/export/icon/variants/*.svg`.

Рендер PNG: headless Firefox снимает SVG напрямую —
`firefox --headless --no-remote --profile <tmpdir> --window-size=W,H --screenshot out.png file:///…/icon.svg`
(или оберни SVG в минимальную HTML-страницу без полей). Проверь командой `file`, что размеры точно
1024 / 256 / 128 / 64 / 48 и что у основной иконки нет прозрачных пикселей по краям.

Монохромной версии нужен прозрачный фон, а скриншот Firefox непрозрачный — проверь результат. В системе нет
PIL / ImageMagick / Inkscape; есть python3 (стандартная библиотека), node 24, g++; в репозитории есть
`source/third_party/stb_image.h`, `stb_image_write.h` и чистый Python PNG-writer в `tools/make_icon.py`.
Если нужно — напиши маленький конвертер сам (например, альфа из яркости рендера «белое на чёрном») и сохрани
в `design/tools/`. Не выдавай непрозрачный PNG за прозрачный.

Мелкие размеры (64, 48) получай рендером SVG в нужном размере, а не уменьшением 1024; посмотри их глазами
(можно сделать увеличенный контактный лист).

## B) `design/screens/06-icon.html`

- `icon-sizes` — рекомендованная иконка в 1024 (можно показать в 512 с подписью), 256, 128, 64, 48 в ряд +
  монохром на тёмном и светлом фоне.
- `icon-variants` — варианты A / B (/ N) рядом, рекомендация отмечена, по строке обоснования.
- `icon-construction` — построение: сетка, squircle, радиус ~22 %, оптический сдвиг треугольника 2–3 %,
  скругление углов, градиент с точками и hex, охранное поле.
- `icon-context` — условная плитка hbmenu / домашнего экрана Switch (ряд квадратных плиток, наша среди
  нейтральных серых заглушек) на тёмном и светлом фоне, плюс марка 32×32 в app bar. Чужие логотипы не рисовать.
- `illustrations` — см. раздел C.

Иконку вставляй через `<img src="../export/icon/…">`.

## C) SVG-иллюстрации → `design/export/illustrations/`

`empty-feed.svg` («Пока ничего нет»), `empty-search.svg` («Найдите что посмотреть»), `not-found.svg`
(«Ничего не найдено»), `offline.svg` (ошибка сети). 240×160, простые фигуры, без фильтров, растровых эффектов
и текста. Цвета — `currentColor` и/или CSS-переменные с fallback, чтобы работали в обеих темах; задокументируй
роли (фигуры — surfaceContainerHigh / outlineVariant, акцент — primary). В духе M3 Expressive: крупные мягкие
формы (squircle, «печенье», пилюля), один акцент. На странице — фрейм `illustrations` в тёмной и светлой теме
(инлайн-SVG, чтобы подхватились роли).
