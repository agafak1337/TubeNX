# Задание: страница 02 Components

Файл: `design/screens/02-components.html` (ТЗ §5, §9 п.3; плюс §2, §3, §8).
Папка временных рендеров: `/tmp/opencode/agent-components/`.

## Формат

- Каждый компонент — отдельный фрейм, id `cmp-<имя>`; ширина 1280, высота по содержимому (inline у `.frame`).
  Внутри две половины: тёмная тема слева (`.dark`) и светлая справа (`.light`), каждая на своём фоне
  `var(--surface)`, с одинаковым набором вариантов.
- Состояния в ряд с подписями: Default / Hover / Focus / Pressed / Disabled
  (`.is-hover .is-focus .is-pressed .is-disabled`). Именование как в M3.
- Redline у каждого компонента: размеры, паддинги, радиусы, роли цветов (имена ролей, не хексы), типографика.
  Компактный блок-спека под компонентом (Google Sans 12 px) плюс, где уместно, выноски `.redline`.
- Disabled — 38 % opacity. Тач-таргет ≥ 48: для элементов ниже 48 px (чип 32, кнопка S/M, switch) покажи
  выноской зону нажатия 48.

## Компоненты (все обязательны)

1. Button: filled, tonal, outlined, text, elevated; с иконкой слева и справа; размеры S 32 / M 40 / L 48.
2. Icon button: standard, filled tonal, filled; 40 / 44 / 48.
3. FAB — не рисовать; одной строкой: «не используется: нет основного действия».
4. Chip: assist, filter, input; selected/unselected; плюс чип поверх видео (`.chip.on-video` на тёмной
   подложке-кадре).
5. Segmented button: 2, 3, 4 сегмента, с иконками и без.
6. Switch 52×32, thumb 24: off/on, с иконкой внутри, все состояния.
7. Slider: continuous, с value label; вариант на видео (буфер + прогресс).
8. Search bar 52 px, full radius: пусто (placeholder «Поиск на YouTube»), с текстом и кнопкой close, фокус.
9. Card: filled, outlined, elevated.
10. List item: 1, 2, 3 строки, leading icon, trailing slot (switch / chevron / текст).
11. Dialog: basic + подтверждение удаления истории («Очистить историю?» / «История просмотров и локальные
    рекомендации будут удалены с этой консоли.» / «Отмена», «Очистить») + «Закрыть видео?» из ТЗ §8.
12. Snackbar / toast: 1 строка + действие, низ по центру, автоскрытие 3 с (в спеке).
13. Progress: linear 2 и 4 px (определённый и неопределённый), circular 20 / 22 / 32.
14. Top app bar small 72 px: вариант Home (марка + название + иконки) и вариант с «назад» и заголовком.
15. Navigation bar — КОНЦЕПТ, 80 px, 3 пункта (Главная, Поиск, Настройки): отдельным фреймом с пометкой
    «Concept — в текущей архитектуре нет».
16. Empty state: иконка 64, заголовок, текст, кнопка.
17. Skeleton: обложка, строка, карточка (без шиммера; в спеке — пульсация opacity 0.6→1.0 за 1.2 с).
18. Focus ring: 3 px primary, радиус = радиус элемента + 2; показать на кнопке, чипе, icon button, карточке
    видео поверх светлой и тёмной обложки (фокус должен читаться на любом фоне), сегменте, строке списка.
19. Карточка видео (`.vcard`) и «Продолжить просмотр» (`.ccard`): default / hover / focus / pressed; отдельно
    — карточка с названием из 120 русских символов (обрезка 2 строками, высота карточки не меняется).

## Замечания

- Базовые стили уже есть в `components.css` и `app.css` — используй их. Чего не хватает (input chip с
  крестиком, navigation bar, неопределённый прогресс, недостающие состояния) — допиши в `<style>` страницы.
- Светлую тему проверь особенно внимательно: общие стили писались под тёмную. Если состояние выглядит плохо —
  переопредели у себя и приведи в отчёте точный CSS, который надо перенести в общий файл.
