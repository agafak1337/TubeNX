# Задание: экраны Search и Settings

ТЗ §4.3 и §4.5 (плюс §2, §3, §7, §8). Папка временных рендеров: `/tmp/opencode/agent-search-settings/`.
Все фреймы 1280×720, если не сказано иное.

## A) `design/screens/03-screens-search.html` (ТЗ §4.3)

Шапка: кнопка назад 44×44 слева, справа от неё search bar 52 px (радиус 26, surfaceContainerHigh, иконка
search 24, placeholder «Поиск на YouTube», close при введённом тексте). Клавиатура системная — не рисовать.

Фреймы (тёмная тема):

- `search-empty` — иконка search 64 по центру (y≈200), «Найдите что посмотреть» headlineSmall, «Нажмите на
  поле — откроется клавиатура Switch» bodyMedium; ниже «Недавние» и до 4 строк истории: иконка history,
  название, канал; разделитель outlineVariant 1 px.
- `search-empty-no-history` — то же без «Недавних».
- `search-focus-field` — фокус геймпада на поле поиска.
- `search-suggest` — введён текст, под полем карточка подсказок: радиус 16, до 6 строк по 48 px, иконка
  history (история) / search (подсказка), текст bodyLarge, справа north_west. Тень допустима только здесь.
  Одна строка в фокусе.
- `search-results` — та же сетка, что на Home (`.grid` / `.vcard`), 2 ряда; запрос остаётся в поле.
- `search-results-focus` — фокус на карточке результата.
- `search-loading` — скелетоны, 8 карточек.
- `search-not-found` — иконка search_off, «Ничего не найдено», пояснение одной строкой, кнопка
  «Изменить запрос».
- `search-error` — ошибка сети: карточка errorContainer 560 px, как на Home (cloud_off, «Повторить» filled,
  «Настройки» text).

## B) `design/screens/03-screens-settings.html` (ТЗ §4.5)

Top app bar 72 с «назад» и заголовком «Настройки» (headlineSmall). Две колонки по 560 px, зазор 24.
Карточки: радиус 20, surfaceContainerLow, паддинг 20; над каждой микрозаголовок секции (`.overline`:
titleSmall, primary, caps, letterSpacing +0.5). Контент скроллится.

Фреймы:

- `settings-top` — то, что видно без прокрутки.
- `settings-scrolled` — прокручено: app bar закреплён, видны нижние карточки.
- `settings-full` — весь контент одной высокой доской (1280×нужная высота, inline), все 6 карточек целиком.
- `settings-focus` — фокус геймпада на сегменте; плюс фрейм-лист `settings-focus-states` с увеличенными
  фрагментами: фокус на switch, кнопке, кружке seed.
- `settings-disabled` — «Обход блокировок» выключен: зависимые контролы 38 % opacity, статус «нет соединения»
  ролью error, строка «Прокси отключён», последняя ошибка ролью error в 1 строку.
- `settings-top-light`, `settings-full-light` — светлая тема (`.light`).
- `settings-dialog` — диалог «Очистить историю?» поверх экрана со скримом (текст: «История просмотров и
  локальные рекомендации будут удалены с этой консоли.», кнопки «Отмена» и «Очистить»).
- `settings-seed-blue` — тот же верх с синим seed (`.seed-blue` у фрейма): палитра перекрашивает интерфейс.
- `settings-layout-variants` — сравнение раскладок (см. ниже).

Содержимое карточек — строго по ТЗ §4.5:

1. «ОБХОД DPI • BYEBYEDPI»: «Обход блокировок» + switch; описание; segmented Split / Multi / Disorder / TLS
   на всю ширину, высота 40; кнопка «Проверить доступ» (tonal, иконка wifi) и рядом статус
   «YouTube: 128 мс» ролью tertiary; «Соединений: 12 • фрагментов: 8 • трафик: 3,4 МБ»; «Прокси: …» /
   «Прокси отключён»; «SNI-обход: вкл • TLS: имя + цепочка»; последняя ошибка — error, 1 строка.
2. «ОФОРМЛЕНИЕ • MATERIAL 3»: «Тёмная тема» + switch, подпись «M3 tonal palette, автоматически»; палитра
   seed: 6 кружков 32 px (красный, синий, зелёный, фиолетовый, оранжевый, розовый) — цвета через
   `var(--seed-red)` и т.д.; выбранный — кольцо 2 px primary + галочка; зона нажатия каждого 48×48.
3. «ВИДЕО»: качество по умолчанию Авто / 720p / 480p / 360p (segmented); «Автовоспроизведение следующего
   видео» + switch.
4. «ЗВУК • СИНХРОНИЗАЦИЯ С ВИДЕО»: «Сдвиг звука», значение «0 мс», кнопки −50 / +50 / Сброс, подпись
   «Если звук отстаёт от картинки — сдвиньте в плюс».
5. «ИСТОРИЯ И РЕКОМЕНДАЦИИ»: «Локальные рекомендации» + switch, «История хранится только на этой консоли»,
   кнопка «Очистить историю» (text, error).
6. «О ПРИЛОЖЕНИИ»: «TubeNX 1.0», «Material 3 Expressive • Google Sans», «Сборка: …», «Лицензии open source»
   (text-кнопка); мелким текстом горячие клавиши из ТЗ §8: A — выбрать, B — назад, Y — пауза,
   L/R — ±30 с, ←/→ — ±10 с.

Замечания:

- В ТЗ §7 секция звука названа «Звук и синхронизация», в §4.5 — «ЗВУК • СИНХРОНИЗАЦИЯ С ВИДЕО». В макете
  используй вариант §4.5 и упомяни расхождение в отчёте.
- Посчитай контраст цветных статусов (tertiary, error, primary-микрозаголовок) на surfaceContainerLow в обеих
  темах, особенно в светлой; числа — в отчёт. Если не проходит 4.5:1 — не скрывай, покажи как есть.
- Карточки распредели по колонкам так, чтобы высоты колонок были примерно равны.
- Раскладка: «две колонки по 560, зазор 24, поля 24» = 1168 px, справа остаётся 112 px. На фрейме
  `settings-layout-variants` покажи рядом: (A) колонки прижаты влево, как в ТЗ буквально; (B) блок из двух
  колонок по центру (поля по 56 px). Отметь рекомендацию и основной макет рисуй по ней.
- Чего нет в общих CSS (кружки seed, строка настроек, степпер сдвига звука) — в `<style>` своей страницы.
