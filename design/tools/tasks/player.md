# Задание: страница 04 Player

Файл: `design/screens/04-player.html` (ТЗ §4.4, §9 п.5; плюс §2, §3, §7, §8).
Папка временных рендеров: `/tmp/opencode/agent-player/`. Все фреймы 1280×720, класс `frame video dark`.

«Кадр видео» под контролами — заглушка: 2–3 условных кадра CSS-градиентами и простыми фигурами (один
светлый/яркий, один тёмный), чтобы проверить читаемость контролов на разном фоне. Никакого blur.

## Геометрия (строго по ТЗ §4.4)

- Верхний скрим: чёрный 72 % → 0 %, высота 190; нижний: 0 % → 86 %, высота 240 (`.scrim-top`, `.scrim-bottom`).
- Назад 48×48 слева сверху (белая иконка); справа сверху ничего.
- Заголовок: 1 строка titleLarge, белый, x=76, y=20, не доходит 300 px до правого края (ellipsis); ниже канал
  + «• 720p», bodySmall, белый 78 %.
- Центр: play/pause в круге 84×84 (чёрный 35 %, иконка 40).
- Таймкод слева `00:00`, справа длительность, labelMedium, белый.
- Дорожка прогресса: зона нажатия 44 px, линия 4 px, буфер белый 30 %, прогресс primary, ползунок 14 px;
  при фокусе линия 6 px.
- Ряд кнопок на y = 720−72: replay_10, forward_10, volume_up + слайдер громкости 140 px; справа: лайк
  (thumb_up), чип качества «720p», чип статуса обхода («SNI-обход» / «Обход DPI: прокси»), more_vert.
- Чипы на видео: white 14 %, белый текст, высота 36, радиус full.
- Капсула буферизации по центру сверху (y=120): спиннер + «Буферизация…».
- Свёрнутые контролы: только полоса 3 px сверху (белый 18 % + прогресс primary).

Координаты, заданные в ТЗ явно, соблюдай как есть. Если из-за этого интерактивный элемент попадает в
5 %-зону ТВ — не двигай молча, перечисли такие элементы в отчёте. Цвет прогресса — `var(--primary)`
(в тёмной теме это светло-розовый #FFB2B4, так задано ТЗ).

## Фреймы

- `player-controls` — контролы видимы, идёт воспроизведение (в центре pause).
- `player-controls-bright` — то же на светлом кадре (проверка скримов и контраста).
- `player-hidden` — контролы свёрнуты: только полоса 3 px сверху.
- `player-paused` — пауза: контролы видны, видео затемнено на 12 %, в центре play_arrow.
- `player-buffering` — капсула «Буферизация…».
- `player-loading` — спиннер 22 px по центру + «Получаем потоки…» на чёрном.
- `player-error` — карточка 640×260 surfaceContainerHighest: иконка error, «Не удалось воспроизвести», текст
  ошибки (3 строки, ellipsis), «Повторить» (tonal) и «Назад» (text).
- `player-ended` — конец видео: контролы + «Смотреть снова» по центру (иконка replay).
- `player-ended-related` — ПРЕДЛОЖЕНИЕ (пометь так в подписи): полоса «Похожие видео» из 3–4 карточек над
  нижним рядом.
- `player-quality-menu` — меню качества над чипом «720p»: Menu M3, surfaceContainer, радиус 16, пункты 48 px
  (Авто, 1080p, 720p, 480p, 360p), выбранный — галочка + secondaryContainer. Тень допустима.
- `player-more-menu` — меню more_vert над нижним рядом («Скорость: обычная», «Субтитры: выкл»,
  «Сдвиг звука: 0 мс»).
- `player-focus-seek` — фокус геймпада на дорожке (линия 6 px, увеличенный ползунок, value label с временем).
- `player-focus-button` — фокус на кнопке нижнего ряда и отдельно на чипе: кольцо должно читаться поверх
  видео (3 px primary + подложка / утолщение — одного цвета на видео мало, ТЗ §8).
- `player-liked` — лайк активен (залитая иконка, акцент primary) + тост «Учтём в рекомендациях».
- `player-close-dialog` — диалог «Закрыть видео?» со скримом: «Воспроизведение остановится.», кнопки «Отмена»
  и «Закрыть».
- `player-proxy-chip` — чип статуса «Обход DPI: прокси» и состояние с выключенным обходом (чип скрыт или
  «Без обхода» — выбери и обоснуй).
- `player-redline` — `player-controls` с выносками `.redline`: высоты скримов, x/y заголовка, 84×84, зона 44
  и линия 4, y ряда кнопок, высота чипа 36, слайдер 140.

## Проверки

- Нижний ряд не налезает на дорожку и таймкоды; между тач-таргетами ≥ 8 px, каждый ≥ 48×48 (чип 36 px — зона
  нажатия 48).
- Название видео из 120 русских символов на одном из фреймов: обрезается одной строкой.
- Чего нет в общих CSS — в `<style>` своей страницы.
