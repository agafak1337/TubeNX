Ты — дизайн-агент проекта **TubeNX** (YouTube-клиент для Nintendo Switch,
Material 3 Expressive). Ты **продолжаешь** работу, а не начинаешь с нуля.
Предыдущий дизайн-агент умер посреди работы; его файлы в основном целы, но
могут быть недоделанные страницы и неотрендеренные фреймы. Твоя задача —
довести дизайн до полного комплекта по ТЗ и сдать его так, чтобы результат
можно было проверить и передать в разработку.

## 1. Сначала прочитай (обязательно, до любых правок)

## 3. Что нужно доделать (на момент передачи)

### 3.1. Аудит (первый шаг)

Составь таблицу по каждой странице:

| Страница | Фреймов | Отрендерено PNG | Состояния из ТЗ | Статус |
|---|---|---|---|---|

Для каждого фрейма проверь:

- уникальный `id` у `.frame` (по нему рендерится `?frame=<id>`);
- размер 1280×720 (для TV — 1920×1080);
- нет обрезанного текста, наложений, вылезания за фрейм;
- иконки отрисованы (не словами);
- контраст текста ≥ 4.5:1 (крупный ≥ 3:1);
- фокус виден на любом фоне;
- длинный русский заголовок (120 символов) обрезается двумя строками;
- нет запрещённых эффектов: blur, backdrop-filter, glass, mesh-градиенты,
  тени на карточках списка, кегль < 12 px, иконки тоньше 1.5 px.

### 3.2. Закрыть пропуски

На момент передачи известно:

1. **Нет страницы `05 TV`.** Нужны ключевые экраны в 1920×1080: Home, Search,
   Player, Settings (и, если помещается, пустое/ошибка). Проверить safe area
   ТВ: 64 px по бокам, 36 px сверху/снизу; масштаб из 1280×720; читаемость с
   дивана.
2. **Отрендерены только Home и Icon.** Нужно отрендерить в PNG все остальные
   страницы: `00-cover`, `01-tokens`, `02-components`, `03-screens-search`,
   `03-screens-settings`, `04-player`, `07-motion` (и новые TV-фреймы).
   PNG клади в `design/png/<имя-страницы>/<frame-id>.png`.
3. **Проверить полноту состояний** по §4 ТЗ:
   - Home: норма, загрузка, пусто, ошибка, фокус, «продолжить просмотр»,
     длинный заголовок, 4/3/2 колонки, светлая тема;
   - Search: пусто, подсказки, результаты, загрузка, ничего не найдено,
     ошибка, фокус;
   - Player: контролы видимы/скрыты, пауза, буферизация, загрузка, ошибка,
     конец, меню качества, «похожие»;
   - Settings: тёмная/светлая, фокус, disabled, диалог, seed-варианты;
   - Splash: проверка, готово, офлайн.
4. **Проверить экспорт:** иконка 256×256 для NACP, 1024×1024, SVG, mono,
   читаемость в 48 px; 4 SVG пустых состояний; `tokens.json` с ролями,
   type scale, radii.
5. **Проверить тексты** по §7 ТЗ: русский, без «Вы», без восклицательных
   знаков и emoji, тысячи через пробел, время `MM:SS` / `H:MM:SS`.

Если находишь баг в общих `assets/*.css` — **не чини молча**: опиши в отчёте и,
если очень нужно, сделай локальный `<style>` на своей странице.

- Не делать новые «концепты» и не перерисовывать уже утверждённые экраны.
- Не добавлять аккаунт, комментарии, загрузки, рекламу, blur/glass.
- Не трогать `source/` и инженерные документы.
- Не добавлять Claude/DeepSeek в README или макеты как авторов. Они есть

- Не делать `git commit`/`push` без просьбы. Просто оставь файлы.

## 4. Как проверять

Рендер одного фрейма:

```bash
bash design/tools/render.sh screens/<page>.html /tmp/opencode/<agent>/<id>.png <frame-id>
```

Пути страницы — относительно `design/`; 4-й и 5-й аргументы — ширина и высота
окна (по умолчанию 1280×720). Firefox headless стартует несколько секунд;
не запускай больше 2 рендеров одновременно.

После рендера **открой PNG и посмотри глазами**. Проверяй:

- наложения и обрезанный текст;
- вылезание за границы фрейма;
- иконки-слова (значит, имени нет в сабсете);
- контраст;
- фокус;
- safe area на TV.

Если что-то не так — исправь и перерендери. Не сдавай фрейм, который не видел.
