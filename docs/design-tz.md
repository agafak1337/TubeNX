# ТЗ на дизайн TubeNX — YouTube-клиент для Nintendo Switch (Material 3 Expressive)

Документ для дизайн-агента. Задача — сделать **настоящий Material 3 Expressive** дизайн
существующего приложения, а не «красивую картинку»: всё, что нарисовано, должно лечь
в текущий программный рендерер без переделки архитектуры.

---

## 1. Продукт

**TubeNX** — homebrew-клиент YouTube для Nintendo Switch.

- Запускается из hbmenu (иконка + NACP), без установки и без аккаунта.
- Вход: тачскрин (handheld), геймпад (dock/TV), кнопки `A/B/X/Y`, `L/R`, `D-pad`.
- Выход: 1280×720 (handheld) и 1920×1080 (dock). Интерфейс рисуется в виртуальном
  канвасе **1280×720** и масштабируется целым/дробным коэффициентом. Все размеры в ТЗ —
  в этих 720p-пикселях (1 px ТЗ ≈ 1 dp).
- Язык интерфейса — **русский**. Названия видео/каналов — как на YouTube (любой язык).
- Тёмная тема по умолчанию, светлая — переключателем.
- Ключевая функция — обход DPI-блокировок YouTube. В интерфейсе это подаётся как
  «Обход DPI», без технического жаргона в основных экранах.

### Что уже есть (не менять без причины)

Экраны: `Splash`, `Home`, `Search`, `Player`, `Settings`.
Навигация: `Home → (тап/клик по видео) → Player`, `Home ⇄ Search ⇄ Settings`,
`B` = назад, `A` = выбрать, `Y` в плеере = пауза.

### Чего в приложении нет и не будет

- Аккаунта, подписок, комментариев, лайков на сервере, загрузки видео.
- «Лайк» — локальный, влияет только на локальные рекомендации.
- Никакой анимации, требующей blur/backdrop-filter: рендерер — программный.

## 2. Технические ограничения (важно для макета)

Дизайн должен быть реализуем текущим движком. Ограничения:

| Возможность | Есть? | Как рисовать |
|---|---|---|
| Скруглённые прямоугольники, круги | ✅ | `fillRoundRect`, `fillCircle`, `strokeRoundRect` |
| Линейные / радиальные градиенты | ✅ | `fillLinearGradient`, `fillRadialGradient` |
| Мягкая тень | ✅, но дорогая | только для всплывающих поверхностей, не для карточек в списке |
| Обрезка (clip) | ✅ | скроллы, обложки |
| Размытие фона (blur, glassmorphism) | ❌ | используйте тональные поверхности + скрим |
| Пиксельные тени/свечения на каждом элементе | ❌ | M3 elevation = тональная поверхность + outline |
| Иконки | ✅ Material Symbols (сабсет) | 24 px сетка, заливка, `currentColor` |
| Шрифт | Google Sans / Google Sans Text | только с кириллицей |
| Частота кадров | 60 fps | избегать полноэкранных градиентов на каждом кадре |
| Минимальный кегль | 12 px | меньше — нечитаемо на TV с дивана |
| Минимальная зона нажатия | 48×48 px | тач; для геймпада — видимый фокус |

**Нельзя** предлагать: blur, frosted glass, анимированные mesh-градиенты, Lottie,
видео-фоны, 3D, тени слоями, шрифты без кириллицы, иконки тоньше 1.5 px.

## 3. Визуальный язык

### 3.1. Направление

Material 3 Expressive: крупные скругления, выразительная типографика, цветовые
контейнеры вместо теней, «мягкие» формы (squircle), активные состояния с заливкой
`primaryContainer`, спокойный фон.

Настроение: **тёмный кинотеатр + дружелюбный пульт**. Не «офисное приложение»,
не «игровая неоновая панель». YouTube-красный — только акцент (логотип, прогресс,
лайк), не заливка всего экрана.

### 3.2. Цвет

Базовая схема генерируется из seed-цвета (Material You / HCT). Seed — фирменный
красный YouTube, но приведённый к M3-палитре (не чистый `#FF0000`).

Рекомендуемый seed: **`#C3002F`** (глубокий красный). Допустимый вариант: `#B3261E`.

Обязательные роли M3 (обе темы):

```
primary / onPrimary / primaryContainer / onPrimaryContainer
secondary / onSecondary / secondaryContainer / onSecondaryContainer
tertiary / onTertiary / tertiaryContainer / onTertiaryContainer
error / onError / errorContainer / onErrorContainer
background / onBackground
surface / onSurface / surfaceVariant / onSurfaceVariant
surfaceDim / surfaceBright
surfaceContainerLowest / surfaceContainerLow / surfaceContainer
surfaceContainerHigh / surfaceContainerHighest
outline / outlineVariant
inverseSurface / inverseOnSurface / inversePrimary
shadow / scrim
```

Требования:

- Контраст текста ≥ **4.5:1** (крупный ≥ 3:1), включая `onSurfaceVariant` на
  `surfaceContainer*`. Проверить в обеих темах.
- `surface` в тёмной теме — не чёрный: `#111318`-диапазон. Чёрный допустим только
  в полноэкранном плеере (letterbox).
- Обложки видео — главный источник цвета на экране. Фон не должен с ними спорить.
- Статусные цвета (успех/предупреждение) — из `tertiary`/`error`, не вводить
  произвольные зелёные/жёлтые, кроме индикатора «сеть ок» (можно `tertiary`).

### 3.3. Типографика

Семейства: **Google Sans** (Display/Headline/Title), **Google Sans Text**
(Body/Label). Оба — с кириллицей. Fallback — Roboto с кириллицей.

Шкала для канваса 720p (можно масштабировать на 1080p как есть):

| Роль | Кегль / интерлиньяж | Начертание | Где |
|---|---|---|---|
| displaySmall | 36 / 44 | Regular | сплэш |
| headlineMedium | 28 / 36 | Regular | заголовки пустых состояний |
| headlineSmall | 24 / 32 | Regular | заголовок экрана |
| titleLarge | 22 / 28 | Medium | название видео в плеере |
| titleMedium | 16 / 24 | Medium | название карточки, заголовок карточки настроек |
| titleSmall | 14 / 20 | Medium | подписи секций |
| bodyLarge | 16 / 24 | Regular | основной текст |
| bodyMedium | 14 / 20 | Regular | описания, вторичный текст |
| bodySmall | 12 / 16 | Regular | технические подписи |
| labelLarge | 14 / 20 | Medium | кнопки, чипы |
| labelMedium | 12 / 16 | Medium | бейджи |
| labelSmall | 11 / 16 | Medium | микро-подписи (только не критичное) |

Правила:

- Названия видео — **не более 2 строк**, затем ellipsis.
- Название канала — 1 строка, `onSurfaceVariant`.
- Не использовать ALL CAPS для русских слов (кроме микрозаголовков секций вида
  «ОБХОД DPI» — допустимо, с `letterSpacing +0.5`).
- Не использовать курсив.

### 3.4. Формы и сетка

- Базовая сетка — **8 px**. Отступы: 8 / 12 / 16 / 24 / 32.
- Поля экрана — 24 px слева/справа.
- Радиусы M3: 8 (small), 12 (medium), 16 (large), 28 (extraLarge), 999 (full).
  Карточки видео — 16, крупные контейнеры — 24–28, чипы/кнопки — full.
- Тач-таргет ≥ 48×48. Между соседними тач-таргетами ≥ 8 px.
- Фокус геймпада: 3 px `primary` снаружи элемента + лёгкая заливка
  `primaryContainer` (не полагаться только на цвет — добавить утолщение).
- Безопасные зоны ТВ: 5% по краям (64 px по 1280, 36 px по 720) — ничего
  интерактивного в них.

### 3.5. Движение

- Стандартные кривые M3: emphasized `cubic-bezier(0.2, 0, 0, 1)`, 200–300 мс.
- Появление контролов плеера — fade + сдвиг 8 px, 180 мс.
- Скролл — инерционный, без «резинки».
- Никаких бесконечных декоративных анимаций. Прогресс-индикатор — единственная
  постоянная анимация.

## 4. Экраны и состояния

Для каждого экрана нужны: **нормальное состояние, загрузка, пусто, ошибка**,
фокус геймпада, нажатое состояние. Ниже — обязательный минимум.

### 4.1. Splash

- Фон `surface`, по центру: логотип-марка (play-треугольник в squircle) 96×96,
  ниже «TubeNX» (`displaySmall`), ниже статус подключения (`bodyMedium`,
  `onSurfaceVariant`): «Проверяем соединение…» → «Готово» / «Нет сети».
- Тонкий линейный прогресс `primary` под логотипом (незавершённый, 2 px).
- Снизу мелко: «Material 3 Expressive • Google Sans» (`bodySmall`, 60% opacity).
- Никаких кнопок: сплэш живёт 1–3 с и уходит сам.

### 4.2. Home

Структура сверху вниз:

1. **Top app bar** — 72 px, `surface`, без тени.
   - Слева: марка 32×32 (squircle `primary`, белый play) + «TubeNX» (`titleLarge`).
   - Справа: иконки `search`, `settings` (44×44, `onSurfaceVariant`), между ними 8 px.
   - Индикатор сети: точка 7 px (`tertiary`) рядом с иконками, только когда сеть ок.
2. **Ряд чипов** — 48 px, горизонтальный скролл, отступ сверху 4 px.
   Чипы: `Главная`, `В тренде`, `Музыка`, `Игры`, `Новости`, `Подкасты`.
   - Выбранный: `secondaryContainer` / `onSecondaryContainer`, галочка не нужна.
   - Остальные: `outlineVariant` 1 px + прозрачный фон, `onSurfaceVariant`.
   - Высота чипа 32, радиус full, паддинги 16/8.
3. **«Продолжить просмотр»** — полоса 148 px, только если есть история.
   - Заголовок 14 px `titleSmall`, 24 px от левого края.
   - Горизонтальные карточки 240×135 (16:9), радиус 12, снизу тонкий прогресс
     просмотра 3 px `primary` и название 1 строка.
   - Между карточками 12 px.
4. **Сетка видео** — 4 колонки при 1280.
   - Ширина карточки: `(1280 − 48 − 3×16) / 4 = 296`.
   - Обложка 296×166 (16:9), радиус 16.
   - Под обложкой 8 px: название 2 строки (`titleMedium`, 16/22), ниже канал
     (`bodySmall`, `onSurfaceVariant`), ниже метаданные «1,2 млн просмотров • 3 дня назад».
   - Бейдж длительности в правом нижнем углу обложки: чёрный 70%, белый текст
     `labelMedium`, радиус 6, паддинг 6/2.
   - При наведении/фокусе: обложка чуть светлеет (overlay 6% white), поверх —
     иконка play в круге 48 px (чёрный 45% + белый треугольник). Не двигать карточку.
   - Сетка должна выдерживать 2, 3, 4 колонки (адаптив под ширину, кратно 296+16).
5. **Низ** — резерв 88 px под системную подсказку/тосты. Нижнюю навигацию
   можно предложить как концепт, но в текущей архитектуре её нет; если предлагаете —
   нарисуйте отдельным фреймом «Concept: bottom navigation» (3 пункта: Главная,
   Поиск, Настройки) и не смешивайте с основным макетом.

Состояния:

- **Загрузка**: скелетоны карточек (surfaceContainerHigh, без шиммера-градиента,
  допустима пульсация прозрачности 0.6→1.0 за 1.2 с), 8 шт.
- **Пусто**: иконка `video_library` 64 px `surfaceVariant`, заголовок
  «Пока ничего нет», текст «Обновите ленту или проверьте обход DPI», кнопка
  «Обновить» (tonal).
- **Ошибка**: карточка по центру 560 px, `errorContainer`, иконка `cloud_off`,
  текст ошибки 2 строки, кнопки «Повторить» (filled) и «Настройки» (text).

### 4.3. Search

1. **Search bar** — 52 px высотой, радиус full (26), `surfaceContainerHigh`,
   слева иконка `search` 24 px, placeholder «Поиск на YouTube», справа `close`
   при введённом тексте. Слева от поля — кнопка назад 44×44.
2. **Подсказки** (если есть) — карточка под полем, радиус 16, до 6 строк по 48 px,
   иконка `history`, текст `bodyLarge`. Тень допустима только здесь.
3. **Пустое состояние**:
   - иконка `search` 64 px `surfaceVariant` по центру (y≈200),
   - «Найдите что посмотреть» (`headlineSmall`),
   - «Нажмите на поле — откроется клавиатура Switch» (`bodyMedium`).
   - Ниже — «Недавние» и до 4 строк истории: иконка `history`, название,
     канал. Разделитель `outlineVariant` 1 px.
4. **Результаты** — та же сетка, что на Home, с тем же поведением.
5. **Состояния**: загрузка (скелетоны), «Ничего не найдено» (иконка `search_off`,
   кнопка «Изменить запрос»), ошибка сети (как на Home).

Клавиатура — системная (Switch), рисуем только поле и подсказки.

### 4.4. Player

Полноэкранное видео 1280×720, чёрный фон. Все элементы — поверх видео.

**Контролы (видимы 3 с после действия):**

- Верхний скрим: градиент чёрный 72% → 0% на высоту 190 px.
- Слева назад 48×48 (белая иконка), справа — ничего (меню «ещё» внизу).
- Заголовок видео: 1 строка `titleLarge` белый, x=76, y=20, ширина до 300 px от
  правого края. Ниже: канал + «• 720p» `bodySmall` белый 78%.
- Центр: кнопка play/pause в круге 84×84 (чёрный 35%, белая иконка 40 px).
- Нижний скрим: 0% → 86% на высоту 240 px.
- Таймкод слева `00:00`, справа общая длительность, `labelMedium` белый.
- Дорожка прогресса: высота 44 px (зона нажатия), видимая линия 4 px,
  буфер — белый 30%, прогресс — `primary`, ползунок 14 px. При фокусе — 6 px.
- Ряд кнопок (y = 720−72): `replay_10`, `forward_10`, `volume_up` + слайдер
  громкости 140 px, затем справа: лайк, чип качества («720p»), чип статуса
  обхода («SNI-обход» / «Обход DPI: прокси»), `more_vert`.
- Чипы на видео: фон white 14%, белый текст, высота 36, радиус full.
- Индикатор буферизации: капсула по центру сверху (y=120), спиннер + «Буферизация…».
- Свёрнутые контролы: только тонкая полоса 3 px сверху (белый 18% + прогресс
  `primary`).

**Состояния:**

- Загрузка: спиннер 22 px по центру + «Получаем потоки…».
- Ошибка: карточка 640×260 `surfaceContainerHighest`, иконка `error`, заголовок
  «Не удалось воспроизвести», текст ошибки (3 строки), кнопки «Повторить» (tonal)
  и «Назад» (text).
- Пауза: контролы видны, видео затемнено на 12%.
- Конец видео: контролы + кнопка «Смотреть снова» по центру.

**Не рисовать** настройки качества отдельным экраном: это чип-меню, всплывающее
над нижним рядом (Menu M3: `surfaceContainer`, радиус 16, пункты 48 px,
выбранный — галочка + `secondaryContainer`).

### 4.5. Settings

Две колонки по 560 px (зазор 24, поля 24). Верх — top app bar 72 px с назад и
заголовком «Настройки» (`headlineSmall`). Контент скроллится.

Карточки (радиус 20, `surfaceContainerLow`, паддинг 20):

1. **«ОБХОД DPI • BYEBYEDPI»** (`titleSmall`, `primary`)
   - Заголовок «Обход блокировок» + switch справа.
   - Описание: «Фрагментация TLS ClientHello против DPI-троттлинга YouTube».
   - Сегментированный контрол: `Split / Multi / Disorder / TLS` (полная ширина,
     высота 40, радиус full, выбранный — `secondaryContainer`).
   - Кнопка «Проверить доступ» (tonal, иконка `wifi`), рядом статус:
     «YouTube: 128 мс» (`tertiary`) или «нет соединения» (`error`).
   - Строка статистики: «Соединений: 12 • фрагментов: 8 • трафик: 3,4 МБ».
   - Строка «Прокси: …» или «Прокси отключён».
   - Строка «SNI-обход: вкл • TLS: имя + цепочка».
   - Последняя ошибка — `error`, 1 строка.
2. **«ОФОРМЛЕНИЕ • MATERIAL 3»**
   - «Тёмная тема» + switch, подпись «M3 tonal palette, автоматически».
   - Палитра seed: 5–6 кружков 32 px (красный, синий, зелёный, фиолетовый,
     оранжевый, розовый), выбранный — кольцо 2 px `primary` + галочка.
3. **«ВИДЕО»**
   - Качество по умолчанию: `Авто / 720p / 480p / 360p` (segmented).
   - Автовоспроизведение следующего видео + switch.
4. **«ЗВУК • СИНХРОНИЗАЦИЯ С ВИДЕО»**
   - «Сдвиг звука»: значение «0 мс», кнопки −50 / +50 / Сброс.
   - Подпись: «Если звук отстаёт от картинки — сдвиньте в плюс».
5. **«ИСТОРИЯ И РЕКОМЕНДАЦИИ»**
   - «Локальные рекомендации» + switch, подпись «История хранится только на
     этой консоли».
   - Кнопка «Очистить историю» (text, `error`).
6. **«О ПРИЛОЖЕНИИ»**
   - «TubeNX 1.0», «Material 3 Expressive • Google Sans», «Сборка: …»,
     «Лицензии open source» (text-кнопка).

Состояния: hover/focus на карточках не обязателен, но все интерактивные элементы
обязаны иметь focus-ring. Выключенный контрол — 38% opacity.

## 5. Компонентная библиотека (обязательно отдельной страницей в Figma)

Для каждого компонента — варианты `Default / Hover / Focus / Pressed / Disabled`,
в тёмной и светлой теме. Именование — как в M3.

- Button: filled, tonal, outlined, text, elevated; иконка слева/справа; размеры
  S (32), M (40), L (48).
- Icon button: standard, filled tonal, filled; 40/44/48.
- FAB — не использовать (нет основного действия).
- Chip: assist, filter, input; selected/unselected.
- Segmented button (2–4 сегмента, с иконками и без).
- Switch (52×32, thumb 24, иконки внутри допустимы).
- Slider (continuous, с value label).
- Search bar (52 px, full radius).
- Card: filled, outlined, elevated.
- List item (1–3 строки, leading icon, trailing slot).
- Dialog (basic + подтверждение удаления истории).
- Snackbar / toast (низ по центру, 1 строка + действие, автоскрытие 3 с).
- Progress: linear (2–4 px), circular (20/22/32).
- Top app bar (small, 72 px).
- Navigation bar (концепт, 80 px, 3 пункта) — отдельно.
- Empty state (иконка 64, заголовок, текст, кнопка).
- Skeleton (обложка, строка, карточка).
- Focus ring (3 px, `primary`, радиус = радиус элемента + 2).

Каждый компонент — с redline: размеры, паддинги, радиусы, цвета-роли (не хексы,
а `primary`, `onSurfaceVariant` и т.д.), типографика.

## 6. Иконка приложения (NACP + hbmenu)

Нужен **экспортируемый PNG 256×256**, а также исходник 1024×1024 (Figma/SVG).

- Квадрат, без прозрачности по краям (Switch показывает иконку в квадрате).
- Форма: squircle / M3-«печенье», радиус ~22% (не круг, не просто квадрат).
- Фон: глубокий красный градиент (диагональ, `#C3002F` → `#7A0020`), без шума
  и без мелких деталей.
- Центр: белый play-треугольник со скруглёнными углами (радиус 3–4 px),
  оптически по центру (не геометрически: сдвиг вправо на 2–3%).
- Допустимая идея: треугольник вырезан из буквы «N» или образует «N» с
  контрформой — но только если читается в 64×64.
- Без текста, без теней под треугольником, без обводок.
- Проверить читаемость в размерах 256, 128, 64, 48 px.

Дополнительно: монохромная версия 256×256 (белый знак на прозрачном) — для
документации, не для NACP.

## 7. Тексты (ru)

Тон: короткий, дружелюбный, без канцелярита и без англицизмов, кроме
общепринятых («YouTube», «DPI», «TLS»).

Обязательные строки:

- «Проверяем соединение…», «Готово», «Нет сети»
- «Главная», «В тренде», «Музыка», «Игры», «Новости», «Подкасты»
- «Продолжить просмотр», «Недавние»
- «Поиск на YouTube», «Найдите что посмотреть»,
  «Нажмите на поле — откроется клавиатура Switch»
- «Ничего не найдено», «Пока ничего нет», «Обновить», «Повторить»
- «Получаем потоки…», «Буферизация…», «Не удалось воспроизвести», «Назад»,
  «Смотреть снова», «Похожие видео»
- «Обход блокировок», «Проверить доступ», «Прокси: …», «Прокси отключён»
- «Соединений: … • фрагментов: … • трафик: …»
- «Настройки», «Оформление», «Видео», «Звук и синхронизация»,
  «История и рекомендации», «О приложении»
- «Сдвиг звука», «Если звук отстаёт от картинки — сдвиньте в плюс»
- «История хранится только на этой консоли», «Очистить историю»
- «Материал 3 • Google Sans» — не использовать, писать «Material 3 Expressive»

Правила: без «Вы» с большой буквы, без восклицательных знаков, без emoji.
Числа — с пробелом-разделителем тысяч («1 200 000»), время — `MM:SS` / `H:MM:SS`.

## 8. Доступность и геймпад

- Все действия доступны и тачем, и геймпадом. Фокус перемещается по видимой
  сетке, не «прыгает» через экран.
- Фокус всегда видим: 3 px `primary`, не только цвет — добавьте утолщение
  или светлую подложку.
- `B` = назад на всех экранах, кроме плеера (там `B` закрывает плеер с
  подтверждением, если идёт воспроизведение — диалог «Закрыть видео?»).
- `Y` = пауза в плеере, `L/R` = ±30 с, `←/→` = ±10 с.
- Подписи горячих клавиш — мелким текстом в настройках, не на каждом экране.
- Контраст: проверить в Figma плагином (Stark / Contrast) для всех пар
  текст/фон, включая текст поверх обложек (там обязателен скрим-подложка).

## 9. Что сдать (deliverables)

Figma-файл со страницами:

1. `00 Cover` — название, версия, дата, seed-цвет.
2. `01 Tokens` — color roles (dark/light), type scale, shape scale, spacing,
   elevation. Плюс `tokens.json` (экспорт).
3. `02 Components` — все компоненты и состояния (см. §5), с redline.
4. `03 Screens` — 5 экранов × состояния (норма/загрузка/пусто/ошибка/фокус),
   фреймы 1280×720, тёмная тема; для Home и Settings — ещё светлая тема.
5. `04 Player` — контролы видимые/скрытые, ошибка, буферизация, меню качества.
6. `05 TV` — те же ключевые экраны в 1920×1080 (проверка масштаба и safe area).
7. `06 Icon` — 1024, 256, 128, 64, 48; монохром.
8. `07 Motion` — тайминги и кривые (текстом, без видео).

Форматы экспорта:

- Иконка: PNG 256×256 (NACP) + PNG 1024×1024 + SVG.
- Иллюстрации пустых состояний: SVG (простые фигуры, без растровых эффектов).
- `tokens.json` — роли → hex (ARGB), type scale, radii.
- Redline: размеры в px относительно фрейма 1280×720.

### Критерии приёмки

- [ ] Ни одного эффекта из запрещённого списка (§2).
- [ ] Все цвета — роли M3, не произвольные хексы (кроме seed-палитры и обложек).
- [ ] Контраст ≥ 4.5:1 для текста в обеих темах.
- [ ] Минимальный кегль ≥ 12 px, тач-таргет ≥ 48×48.
- [ ] Названия видео обрезаются 2 строками, ничего не «разъезжается» при
      длинном русском заголовке (проверить строкой из 120 символов).
- [ ] Home выдерживает 4/3/2 колонки без изменения высоты карточки.
- [ ] Состояния загрузки/пусто/ошибка нарисованы для Home, Search, Player.
- [ ] Фокус геймпада виден на любом фоне, включая обложки.
- [ ] Иконка читается в 48 px.
- [ ] Все строки — на русском, по §7.

## 10. Референсы

- Material 3 Expressive (Google I/O 2025): крупные формы, `primaryContainer`,

## 11. Как отдавать результат

Один Figma-файл + `tokens.json` + папка `export/` с иконками и SVG.
В описании к каждому фрейму — короткая спека: сетка, отступы, размеры, роли
цветов. Если что-то в ТЗ допускает трактовку — предложите два варианта рядом
на одном фрейме и отметьте рекомендацию.

Вопросы по ТЗ — списком в начале ответа, не по ходу макета.
