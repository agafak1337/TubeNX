`docs/impl-tz.md` §18 (состав милстоуна), `docs/refactor-tz.md` §5 (пункты),

## Общий маршрут до альфы

1. `[x]` **M0/M1** — каркас, рендерер, сеть (второй агент).
2. `[x]` **M2** — данные и потоки (второй агент + UI-блок: NET-09/11/12, DPI-06/16, YT-02/05/06).
3. `[x]` **M3** — видео/плеер (второй агент). Lifted в `acd5f2d`, проверено: NRO 30 273 662 Б, `test-host` ЗЕЛЕНО.
4. `[x]` **M4 — этот файл** (интерфейс), 37 пунктов; частично только аппаратные замеры.
5. `[x]` **M5 «Доводка»** — CFG/SEC/PERF/DOC/RB/TEST; partial/blocked перечислены в `handoff/deepseek/REPORT.md` §13.
6. `[ ]` **Альфа-тест на Switch** (пользователь) — после M4+M5, один прогон.
7. `[ ]` **`main` + тег `v1.0.0-alpha.1`** — только по явной команде пользователя.

Итого M4: **37 / 37** реализовано; аппаратные замеры (`PL-01`, `RD-09/10/11`) — один прогон на консоли.

## Правила

- Каждый пункт: изменение + host-тест (если применимо) + `make -j` (0
  предупреждений) + `make test-host` (ЗЕЛЕНО) + offscreen-`preview` без регрессий.
- `design/` — read-only. Зоны второго агента (`net/dpi/yt/player`, `Makefile`
  кроме `ICON`, `main.cpp` кроме dock, `tools/{test_host,doctor,deploy,pull-log}.sh`,
  `test_theme.cpp`, `test_{net,dpi}.cpp`, `.github/*`) не трогаю.
- Новые host-тесты (`test_text`, `test_canvas`, `test_strings`) нужно подключить
  в `tools/test_host.sh` — это зона второго агента, согласую union.
