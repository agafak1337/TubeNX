Версии — [SemVer](https://semver.org/lang/ru/). Теги ставятся вручную, только

## [Unreleased]

### Добавлено

- Material 3 UI: динамические роли из seed-цвета, Google Sans, Material
  Symbols, геймпад/тач/курсор, онбординг первого запуска.
- Лента, «В тренде», поиск с подсказками, continuation.
- Плеер libmpv: adaptive 720p (H.264 + AAC), муксованный fallback, seek,
  смена качества, метрики `player metrics:`.
- Локальный SOCKS5 с фрагментацией TLS ClientHello и HTTP-ретранслятор для
  видео; режимы Split/Multi/Disorder/TLS.
- Настройки: тема, качество, скорость, задержка звука, автозапуск, локальные
  рекомендации, обход DPI, внешний прокси, диагностика.
- История просмотров и локальные рекомендации; «Очистить историю»,
  «Сбросить рекомендации».
- Атомарный конфиг и история (`*.tmp` → `*.bak` → `rename`), миграция v1→v2,
  сохранение неизвестных ключей, работа при SD read-only.
- Экран «Лицензии open source», `THIRD_PARTY.md`, `NOTICE`, OFL-текст для
  Google Sans.
- Host-тесты: тема, InnerTube, SOCKS/relay, сеть, конфиг, M3-виджеты;
  `make test-host`.
- Диагностика: `sdmc:/config/TubeNX/diagnostics.txt`, `perf:`-строки,
  `docs/network.md`, `docs/architecture.md`, `docs/hardware-smoke.md`.

### Изменено

- Кадровый ритм: vsync, dirty-флаг, пропуск статичного кадра, построчный
  flush framebuffer.
- SNI для `youtube.com`/`ytimg.com` — в верхнем регистре; для
  `googlevideo.com` — подмена имени с сохранением `Host`.
- SSL-бюджет: 2 сессии UI + 2 зарезервированы под плеер, очередь с дедлайном.
- Таймауты и повторы вынесены в именованные бюджеты (`source/net/timeouts.hpp`).
- Логи: уровни, rate limit, ротация, `build=<sha>` в первой строке.
- Прокси в логах и диагностике редактируется (`user:***@host`).
- Лицензионный раздел README приведён к фактическим лицензиям шрифтов.

### Исправлено

- **GET-запросы уходили как POST** после запроса ленты: порядок `CURLOPT_POSTFIELDS`
  и `CURLOPT_HTTPGET` в переиспользуемом easy-handle. Из-за этого обложки
  отвечали `404`, а видео — отказом (NET-18).
- **Подмена SNI у `*.googlevideo.com` при внешнем прокси** ломала выбор TLS-фронтенда
  CDN: теперь имя не подменяется, если задан внешний SOCKS5/HTTP-прокси (DPI-17).
- **Видео отклонялось с `403` на открытый Range**: CDN требует закрытый диапазон,
  поэтому ретранслятор запрашивает поток кусками по 2 МиБ, склеивает их в один
  непрерывный ответ и уменьшает окно до 256 КиБ, если узел отдаёт не всё видео (DPI-19).
- Индекс режима обхода DPI в настройках больше не сдвигается на `Off`.
- Кнопки диалогов не обрезают длинные подписи («Сбросить»).
- Повторная запись конфига не теряет ключи новой версии.
- Битые строки истории не ломают загрузку; дубликаты схлопываются.

### Известные ограничения

- Сквозное видео на реальной консоли **не подтверждено**: нужен один прогон
  по `docs/hardware-smoke.md`.
- Нет аккаунта Google, DRM и платных подписок.
- Скорость и стабильность сети зависят от провайдера и DPI.
- Бинарник содержит GPL-компоненты (FFmpeg/libmpv); см. `NOTICE`.
